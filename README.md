# 🔐 Password Auditor Tool

## 📋 Project Overview
A real-time password strength analyzer 
that evaluates credential hygiene and 
educates users on creating secure passwords.

## 🎯 Features
- Real-time password scoring (0-100)
- Color-coded strength indicator
- 8 security checks
- Common pattern detection
- Personalized recommendations
- Show/hide password toggle

## 🔧 Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 📊 Security Checks
| Check | Description |
|---|---|
| Min Length | At least 8 characters |
| Uppercase | Contains A-Z |
| Lowercase | Contains a-z |
| Numbers | Contains 0-9 |
| Symbols | Contains !@#$... |
| Long Password | 12+ characters |
| No Patterns | No common words |
| No Repeats | No repeated chars |

## 🔐 Scoring System
| Score | Strength |
|---|---|
| 0-29 | Very Weak |
| 30-49 | Weak |
| 50-69 | Fair |
| 70-84 | Strong |
| 85-100 | Very Strong |
